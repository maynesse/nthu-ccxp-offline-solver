How to use

After importing, refresh the NTHU CCXP login page. When the CAPTCHA loads, its six digits should fill automatically. Nothing is submitted automatically, and you can always correct the answer.

The model is imported once because the original trained model was not bundled. Recognition then runs fully offline.

External GitHub navigation above is only for the one-time, user-initiated model download. The extension itself never downloads the model or sends CAPTCHA data to GitHub, AWS, or any other external service.
